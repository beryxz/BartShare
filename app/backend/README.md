# BartShare API

REST API for **BartShare**, the case-study application for Bart, an attribute-based
access-control language for _bartering_ access to resources. Built with TypeScript, Fastify,
Sequelize, and PostgreSQL.

## Quick Start

```bash
cp .env.example .env     # configure environment variables
npm install
npm run dev              # start dev server with hot-reload
```

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for full setup instructions, commands, and project structure.
